✦ About AlFarrizi Studio

AlFarrizi Studio is an independent software development studio focused on building modern, useful, and reliable software.

We create and experiment with applications, APIs, browser extensions, developer tools, automation systems, and open-source projects across multiple platforms and technologies.

Our projects are built around a simple idea:

«Turn interesting ideas into software that people can actually use.»

We enjoy exploring how software works, improving existing experiences, experimenting with new technologies, and creating tools that solve real problems.

✦ Issues & Bug Reports

Found a problem?

Use the Issues section of the relevant repository whenever available.

When reporting a bug, providing detailed information can help us understand and reproduce the problem faster.

Useful information may include:

• Operating system
• Browser or application version
• Steps to reproduce
• Expected behavior
• Actual behavior
• Console logs
• Screenshots
• Error messages

Please avoid including private information, credentials, API keys, access tokens, or other sensitive data in public issues.

---

✦ Security

Security issues should be handled responsibly.

If you discover a vulnerability in one of our projects, avoid publishing sensitive exploit details publicly before the issue has been reviewed.

Whenever available, use the repository's dedicated security reporting feature or instructions.

Please never include:

- Passwords
- Private API keys
- Authentication tokens
- Cookies
- Personal credentials
- Sensitive user data

in public issues or discussions.
